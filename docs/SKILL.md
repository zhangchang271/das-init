# Skill 回顾

`passive-cross-correlation` 是处理连续记录、构建 CCF 并提取 F-J/RT3 观测的工作约定。
本文回顾该 skill 在 das-init 中的对应关系，便于跨机器部署时保留计算依据。
具体执行由仓库程序负责；参数以当前配置和已验证的 San Jose 主流程为准。

迁移时必须连同[数据与计算约定](CONTRACT.md)阅读：每一步除了操作名称，还需说明
提取的信息、物理含义、输入输出轴与单位、分支处理及验收依据。
其中正负支先对应平均为半支，再重建频谱；±1 s 是最终 CCF 输出窗口。
单有一张相似的谱图不足以证明接口与幅值正确，须运行 `scripts/validate_demo.m`。

## 主线

```text
检查输入与几何 → 统一预处理 → 固定窗相关 → 按有效窗数叠加
→ 距离分箱与滤波 → F-J 频散谱及 ridge → 检查并保存结果
```

| Skill 要求 | das-init 中的实现 |
| --- | --- |
| 明确输入、道序、采样率、几何与频带 | BlossomHill HDF5；200 Hz、1 m 道间距；目标道和参考道显式配置 |
| 各道、各片段使用一致的预处理 | 完整读取阵列做 DASQt，再选择目标道；保存预处理参数及缓存信息 |
| 拒绝无效道段并保留有效窗数 | EDWav 选择和 `raw_valid`；无效道不进入 PSD 分母，道对不增加有效窗计数 |
| 记录归一化所在步骤和分母 | mCCFJ 的 PSD 互谱归一化；分母为该窗口有效道的平均功率谱，加固定规则的 epsilon |
| 明确叠加与振幅处理 | 道对按有效窗数线性平均；综合 F-J 为有效日期原始幅值的逐点平均 |
| 区分显示处理与科学计算 | 逐道 RMS 归一化和色阶裁剪只用于显示，不进入 F-J |
| 保留谱、坐标、拾取与处理参数 | 主流程 MAT 与配置记录；`docs/demo/result.mat` 保存便携的频散预览结果 |
| 批处理验收前检查代表性结果 | 对照原 San Jose 500 道结果，并保留真实 50 道 demo 的 CCF 和频散图 |

振幅相关处理中，skill 要求记录完整处理历史；不能悄悄加入 one-bit、白化、逐道归一化、
偏移增益或随日期变化的缩放。保留这些约定，才能解释数据幅值变化来自哪里。

## 参数如何确定

Skill 中的 250 Hz、20 s 相关窗、15 道、`Hamming_1` 等是其他项目的示例。
其原文要求先检查当前生产脚本，不能直接套用。

当前 San Jose 使用 200 Hz、600 s 输入相关窗、PSD、H2 / No-window，默认不做 GW mute；
ridge 使用主流程 `findpeaks` 趋势追踪。最终 CCF 输出裁出 ±1 s 窗口，F-J 使用完整半支重建频谱，不受此输出窗口裁剪影响。
全量示例频段为 1–15 Hz；50 道 demo 为 3–15 Hz。详细参数见配置及[处理说明](PROCESSING.md)。

## 适用范围与尚未完成的部分

该 skill 的范围止于 CCF、频散和衰减等直接观测；Vs、Q、Sw 反演属于后续任务。
需要设计 GW mute 或进行 RT3 衰减验证时，再使用对应的独立 skill。

当前真实数据验收到综合 F-J。demo 保存幅值谱及 ridge，没有复数 F-J、人工 mask 或最终衰减。
后续若分析复数谱峰宽或开展衰减处理，需要补齐对应谱、mask、参数和验证记录。
单个 600 s demo 也不能检查跨日连续性或长时间叠加收敛，不能据此视为这些要求均已完成。
